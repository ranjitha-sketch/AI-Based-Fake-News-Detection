# 🤖 AI-Based Fake News Detection

An AI-powered application that uses Natural Language Processing (NLP) and Machine Learning to classify news articles as real or fake based on patterns learned from a labeled dataset. The project aims to promote media awareness and help users evaluate news content more critically.

## Features

- **Fake News Classification** – Predict whether news resembles real or fake examples.
- **Text Preprocessing** – Clean and prepare news text for analysis.
- **TF-IDF Vectorization** – Convert text into numerical features.
- **Machine Learning** – Use Logistic Regression for classification.
- **Model Evaluation** – Display test accuracy and classification metrics.
- **User-Friendly Interface** – Enter news text and view prediction results.

## How to Use

1. Install the required Python libraries.
2. Prepare a `news.csv` dataset containing `text` and `label` columns.
3. Use label `0` for real news and `1` for fake news.
4. Run the Python application.
5. Train the model using the dataset.
6. Enter a news article or headline to view the prediction.

## Technologies Used

- **Programming Language:** Python
- **Data Processing:** Pandas
- **Machine Learning:** Scikit-learn
- **NLP:** TF-IDF Vectorization
- **Algorithm:** Logistic Regression
- **Interface:** Tkinter (for the GUI version)

## Objective

To explore how Artificial Intelligence and Machine Learning can help identify potentially misleading news and encourage responsible information consumption.
